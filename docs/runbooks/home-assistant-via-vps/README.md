# Home Assistant через VPS (без VPN на клиентах)

Этот пакет документов описывает рабочую схему, где:
- пользователи открывают `home.112prd.ru` / `ha.112prd.ru` без клиентского VPN;
- VPN используется только между домашним сервером и зарубежным VPS;
- доступ публикуется через Cloudflare Tunnel.

## Состав
- `01-architecture.md` — что и как работает.
- `02-implementation-plan.md` — пошаговый план внедрения.
- `03-security-checklist.md` — базовая защита и hardening.
- `04-operations-and-fallback.md` — мониторинг, инциденты, fallback.

## Для чего это
- уменьшить риск блокировок канала к Cloudflare за счет вывода трафика через зарубежный VPS;
- не требовать VPN на телефонах/ПК пользователей;
- сохранить простую эксплуатацию (Cloudflare TLS и маршрутизация).

## Важно
- Не отправляй VLESS-ключи в чаты/публичные места.
- Все секреты храни в локальных защищенных файлах (`600`, root-only).
