# 01. Архитектура

## Цель
Сделать доступ к Home Assistant по домену (`home.112prd.ru`, `ha.112prd.ru`) без включения VPN на клиентах.

## Рекомендованный вариант
`Home server -> (VLESS tunnel) -> VPS abroad -> Internet -> Cloudflare`

При этом:
- `cloudflared` работает на домашнем сервере;
- его egress уходит через локальный прокси (`127.0.0.1:10808`), который поднимает `sing-box`/`xray`;
- DNS в Cloudflare указывает на tunnel hostname (CNAME), не на VPS IP.

## Почему это работает
- Провайдер видит зашифрованный трафик к твоему VPS, а не прямой профиль cloudflared;
- Cloudflare продолжает быть внешней точкой входа и TLS-терминацией;
- клиенту достаточно открыть URL, VPN на устройстве не нужен.

## Альтернатива
`Reverse proxy на VPS` (без Cloudflare Tunnel) — рабочий, но сложнее в поддержке:
- самостоятельный TLS/renew;
- больше поверхности атаки;
- сложнее эксплуатация.
