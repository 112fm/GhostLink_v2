# 04. Эксплуатация и fallback

## Что мониторить
- Статус `cloudflared`.
- Статус `sing-box`/`xray`.
- Время отклика `home.112prd.ru`.

## Базовые проверки
- `systemctl status cloudflared`
- `systemctl status sing-box` (или `xray`)
- HTTP-check на `https://home.112prd.ru`

## Типовые инциденты
1. Не открывается домен:
   - Проверить DNS записи в Cloudflare.
   - Проверить, жив ли tunnel.
2. Tunnel жив, но нет связи:
   - Проверить локальный прокси (`127.0.0.1:10808`).
   - Проверить VLESS до VPS.
3. Периодические отваливания:
   - Проверить keepalive/MTU в транспортном клиенте.
   - Проверить лимиты/файрвол на VPS.

## Fallback-сценарий
- Держать альтернативный транспортный профиль до второго VPS.
- Переключение egress cloudflared на резервный локальный прокси-профиль.
- Иметь быстрый runbook с командами restart/rollback.

## Что не делать
- Не публиковать Home Assistant напрямую в интернет без защитного контура.
- Не хранить ключи/токены в публичных репозиториях.
