# 03. Чек-лист безопасности

## Секреты
- [ ] VLESS ключи не передаются в чаты.
- [ ] Конфиги с секретами: права `600`, владелец `root`.
- [ ] Отдельный пользователь/контекст для сервисов где возможно.

## Сервисы
- [ ] `sing-box`/`xray` в systemd с `Restart=always`.
- [ ] `cloudflared` в systemd с ограниченными правами.
- [ ] Логи ротации включены.

## Сеть
- [ ] На домашнем сервере не открыты лишние входящие порты наружу.
- [ ] SSH защищен (ключи, без password login по возможности).
- [ ] На VPS включен firewall (минимум нужных портов).

## Домены/DNS
- [ ] Cloudflare записи для HA через tunnel CNAME.
- [ ] Не светить origin IP, если он не нужен.
- [ ] Включен HTTPS-only режим на стороне Cloudflare/приложения.

## Мониторинг
- [ ] Проверка доступности `home.112prd.ru` по cron/uptime.
- [ ] Алерт при падении `cloudflared`/`sing-box`.
