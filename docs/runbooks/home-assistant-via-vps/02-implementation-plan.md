# 02. План внедрения

## Шаг 0. Предпосылки
- Есть рабочий VPS (Hetzner).
- Есть домен в Cloudflare.
- Есть домашний сервер с Home Assistant.

## Шаг 1. Поднять транспорт до VPS
1. На домашнем сервере установить `sing-box` (или `xray`).
2. Добавить outbound на твой VLESS Reality сервер.
3. Поднять локальный порт прокси (пример: `127.0.0.1:10808`, SOCKS/HTTP).
4. Завести systemd сервис с `Restart=always`.

## Шаг 2. Привязать cloudflared к локальному прокси
1. Проверить, как запущен `cloudflared` (service/config).
2. Добавить прокси-переменную для сервиса:
   - `ALL_PROXY=socks5://127.0.0.1:10808`
3. Перезапустить `cloudflared`.
4. Убедиться, что tunnel в статусе healthy.

## Шаг 3. Cloudflare DNS/ingress
1. Для `home.112prd.ru` и `ha.112prd.ru` настроить CNAME на tunnel hostname.
2. В cloudflared ingress прописать:
   - `home.112prd.ru -> http://127.0.0.1:8123`
   - `ha.112prd.ru -> http://127.0.0.1:8123` (или второй локальный сервис)
3. Проверить открытие с мобильного интернета без VPN.

## Шаг 4. Проверка отказоустойчивости
1. Остановить `sing-box` и проверить, что tunnel теряет egress.
2. Поднять обратно и убедиться, что доступ восстановился.
3. Проверить автозапуск после reboot.

## Критерий готовности
- С любого клиента без VPN открывается `https://home.112prd.ru`.
- Канал стабилен при длительной работе.
- Сервисы автоматически переживают перезапуск.
