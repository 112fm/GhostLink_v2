# Манифест Заливки На Сервер

Обновлено: 2026-05-27
Охват: текущая синхронизация прода после декомпозиции `api_server.py` и `ghost_final.py`.

## Обязательно заливать на сервер

1. `api_server.py`
2. `ghost_final.py`
3. `backend/` (целиком)
4. `bot/` (целиком, включая `bot/modules/`)

## Заливать только если менялся фронт

1. `webapp-mini-v2/`

## Обычно НЕ заливать

1. `docs/`
2. `Gemini/`
3. `webapp-shared/`
4. `PROXY Ghost/`
5. `.git/`, `.gitignore`, `.gitattributes`, `.editorconfig`
6. `bot/__pycache__/`

## Правило по БД

1. `GhostLink_panel.db` не перезаписывать в проде, если это не осознанная миграция/восстановление.

## Минимальная последовательность перезапуска (на сервере)

1. Перезапустить API-сервис.
2. Перезапустить сервис бота.
3. Проверить, что оба сервиса в статусе `active`.
4. Прогнать быстрый smoke: `/start`, approve/reject оплаты, добавление устройства, базовые admin callbacks.
