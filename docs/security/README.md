# Security Workspace

Единый рабочий контур по безопасности GhostLink.

## Структура

- `plans/SECURITY_MASTER_PLAN.md` — основной план безопасности (актуальный).
- `tasks/SECURITY_TASK_BOARD.md` — доска задач (P0/P1/P2).
- `logs/SECURITY_CHANGELOG.md` — журнал выполненных действий и проверок.

## Правила ведения

1. Любое изменение в проде сначала фиксируется в `tasks/SECURITY_TASK_BOARD.md`.
2. Перед рисковыми действиями обязателен бэкап и ссылка на runbook.
3. После каждого шага: короткая запись в `logs/SECURITY_CHANGELOG.md` (что сделано, результат, откат).
4. В плане не держать «общие слова»: только проверяемые пункты и критерии готовности.
5. Все файлы — UTF-8 без BOM.
