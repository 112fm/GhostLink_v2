# SECURITY_MASTER_PLAN

Обновлено: 2026-05-31.
Статус: active.

## Цель

Повысить безопасность инфраструктуры GhostLink: доступы, сетевой контур, секреты, хостовый hardening, мониторинг и управляемый rollback.

## Ограничение

Работа ведется в рамках легальной защиты сервиса и устойчивости к блокировкам/сбоям. Любые действия должны соответствовать применимому праву и политикам провайдера.

## P0 (критично)

1. Полный аудит Cloudflare по каждому домену проекта.
Критерий готовности:
- Для каждого домена заполнена карточка: `DNS only / Proxied`, SSL/TLS mode, Edge Certificates, WAF, Rate Limiting, Bot Fight, Access Rules, API Shield (если применимо), логика origin-доступа, риск и рекомендация.
- Отдельно отмечены VPN-критичные домены (где проксирование Cloudflare недопустимо для Reality/VLESS).

2. Базовый hardening SSH.
Критерий готовности:
- Запрещен парольный вход после проверки ключей.
- Root login ограничен согласно утвержденной политике.
- Включены allowlist/ограничения по источникам, fail2ban и проверяемые правила firewall.
- Есть проверенный rollback по `sshd_config`.

3. Контроль открытых портов и surface reduction.
Критерий готовности:
- Матрица портов: зачем открыт, кто потребитель, чем защищен.
- Все неиспользуемые порты закрыты.
- Админ-порты не торчат наружу без необходимости.

## P1 (важно)

1. Ревизия управления секретами.
Критерий готовности:
- Инвентарь секретов (`.env`, токены, ключи, SID/PBK, VAPID).
- Политика ротации и дат последней ротации.
- Проверка, что секреты не логируются и не попадают во фронт.

2. Egress и routing hygiene.
Критерий готовности:
- Документирована целевая схема egress.
- Проверено отсутствие циклов маршрутизации.
- Для критичных внешних сервисов есть fallback-сценарии.

3. Наблюдаемость и алерты.
Критерий готовности:
- Единый набор health-check’ов (API, bot, x-ui, SSH).
- Пороговые алерты по ошибкам и доступности.

## P2 (техдолг)

1. Security regression checklist перед каждым релизом.
2. Расширение smoke-тестов на security-сценарии.
3. Формализация еженедельного security-review с коротким отчетом.
